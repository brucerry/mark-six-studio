## 📦 Description

The first Windows and macOS installer release of Mark Six Studio: local draw analysis, model comparisons, and experimental forecasts.

## ✨ Changes

- Offline Windows x64 setup and universal macOS installation wizard.
- Local history retained through upgrades and removal; cached analysis works offline.
- Both platforms pass automated build, package and installer checks; macOS installation also verified on Apple Silicon.
- **Unsigned installers** with SHA-256 checksums. OS approval may be required; see the [installation guide and verification limits](https://github.com/brucerry/mark-six-studio/blob/main/installer/README.md).
